Preparazione file Spoke

Ritiro ingombranti

1. Carica l'estrazione dei ritiri

File Excel (.xlsx), CSV o zip. Puoi selezionare più file insieme (es. due zone di Arezzo): vengono uniti in un unico file. con le colonne Case SAP, Soggetto, Indirizzo e Note. Il file resta nel tuo browser: non viene inviato a nessun server.

2. Risultato

Righe da controllare a mano

RigaCase SAPSoggettoIndirizzoMotivo

Come si usa

  1. Carica l'estrazione dei ritiri (uno o più file) e premi Elabora. Il comune viene letto dall'indirizzo.
  2. Controlla le righe nella tabella: sono quelle con coordinate mancanti o incerte.
  3. Scarica il file e importalo in Spoke. Nella schermata di preview verifica che Address Line 1 sia mappato sull'indirizzo.

Foiano della Chiana: l'indirizzario non basta, le coordinate si prendono da Google Maps.
